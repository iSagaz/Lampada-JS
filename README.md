# 💡 Lâmpada Interativa

Projeto desenvolvido com **HTML, CSS e JavaScript**, com o objetivo de praticar manipulação do DOM, eventos e alteração dinâmica de elementos na página.

## 🚀 Funcionalidades

- Ligar e desligar a lâmpada.
- Alterar visualmente o estado da lâmpada por meio de JavaScript.
- Interação com elementos da página através de eventos.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo do projeto

Consolidar conceitos fundamentais de JavaScript por meio de uma aplicação prática, explorando a manipulação do DOM e a interatividade entre HTML, CSS e JavaScript.
